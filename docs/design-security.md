# 安全不变量与显示边界

本文记录跨模块的长期安全约束；具体生命周期见[连接设计](<design-supervisor.md>)，附件准入见[附件设计](<design-attachments.md>)。修改边界时先核对实现和回归，不能将一次审计通过当作后续改动的保证。

## 命令、认证与进程身份

- 执行命令与凭据去向配置 `command` / `url` 必须使用 machine 作用域，禁止工作区覆盖。
- 端口清理、孤儿锁与 PID 复用只依据肯定的 DSH 进程身份证据；证据不足不操作。shell 外层 PID 不等于服务器 PID，进程查询异步，避免阻塞扩展宿主。
- 会合目录 / 文件在 POSIX 使用 `0o700` / `0o600`，Windows 依靠 profile ACL。
- 启动入口幂等并合并并发；dispose 后在途操作不能复活连接。socket 状态逐字段验形状，行缓冲上限 1 MiB，超限断开。
- 展示日志先经 `redactSecrets`，包括携启动令牌的 stdout；CSP nonce 使用安全随机数。

## 外部输入与资源上限

- 删除会话目录同时检查 `isSafeSessionId` 与解析后的路径包含性，不只验证其中一个。
- 字节附件先检查 base64 长度，单文件上限 8 MB；模型图片路径按服务端单图限额读取，缺省硬上限 64 MB。正文图片按「文件路径图片：执行世界权限边界」处理，不套用附件接入通道的客户端预算。
- 事件 / 会话索引 Map 必须有清理路径；[消息通知](<design-notifications.md>)以稳定身份明确确认，不使用自动消失计时。迟到或重复确认不能吞掉用户尚未看到的新发生；视图只能确认自身可见范围内的通知。新通知与轮次结束均不抢走用户正在使用的输入焦点。
- JSON 清空与快照字段遵守[投影设计](<design-projections.md>)，不以 undefined 表示线上删除。

## 正文图片：有意选择与风险

### HTTPS 外链图片

保留模型回答中的 HTTPS 外链图片，是既定渲染能力；外链请求仍有潜在 URL 外传面，不能因启用 no-referrer / lazy 就声称不存在外传风险。明文 HTTP 图片不放行，日志脱敏也不能代替 URL 准入。

### 文件路径图片：执行世界权限边界

`localImages` 经当前连接的 `HostFileAccess` 在 DSH 执行世界取图。相对路径用创建目录，绝对路径不受创建目录包含性限制；缺创建目录不猜本机工作区。媒体 URL 拒绝 UNC、控制字符和无法取得绝对目标的输入；服务端 `/api/file` 由连接认证保护，使用 `ctx.fs` 的解析、读权限与部署的图片字节限额。路径位于根外或扩展名不在图片表中，本身不是该路由的授权拒绝条件；浏览器显示能力与读取权限分别处理，不套用模型附件的格式准入表。

引用以有界并发全部处理，不再以固定 8 MiB、24 张或扩展名表预先截断。服务端拒绝、离线或能力缺失时不回退本机读盘。认证字节请求不跟随重定向；异步结果绑定发起时的连接与会话，切换后不能写入新范围。文件路由取回字节不代表浏览器可以安全渲染任意主动内容。

`hydrateLocalImages` 在解析回帧前的加载失败不能触发最终降级，否则迟到有效图片无法恢复；失败阶段与最终结果须区分。文件读取与 HTTPS 外链显示仍共同构成潜在外传面，改用执行世界权限后须重新验证，不能沿用「只读创建目录内」的旧安全结论。

## 回归与证据边界

主要防线为 invariants、supervisorProtocol、attachments、localImages、imageHydrate 及各链路回归。CSP、凭据、目录包含性和资源上限不能只用类型检查覆盖。

常规验证与真实探针的批准规则见[AGENTS](<../AGENTS.md>)。有意保留的能力、明确拒绝的输入和尚未验证的环境分别记录；测试通过不等于消除产品接受的残余风险。
