## 维护边界

- 一个主题一份权威说明，其他文档只交叉引用；契约不在设计文档里复制一整份。引用栏目名或符号，不引用易变节号与行号。
- 当前行为以实现与回归为准，旧报告中的失败描述不能作为待修清单。有意不做、尚未实现和尚未验证分别记录，不能混成「已修」或「待办」。
- 待处理问题与待评估能力集中在[ToDo](<../ToDo.md>)，链接回对应设计边界；列入待评估不等于已决定实现。
- 一次性过程、完整审计矩阵与采样报告不留在长期文档；临时材料放 `.agent/`，既有过程可追 Git 历史。只保留解释决策所需的证据与可复现入口，不将历史观察升级为稳定契约。
- 源码导航从[src](<../src/README.md>)进入，工具与离线测试从[scripts](<../scripts/README.md>)进入。离线测试、受控 DOM 和安装端验收是不同证据；真实日志与模型探针遵守当次批准规则。
