# 消息通知

本文约束顶部消息通知与通知历史；领域术语见[领域词表](<../CONTEXT.md>)。消息通知与会话正文、消息发送队列是不同概念。

## 已确定的规则

- 通知队列由当前 VS Code 窗口共享；不跨 VS Code 窗口同步。
- 每条通知可以标注会话 ID；未标注会话 ID 的通知为共享通知。
- 会话视图只展示当前会话的通知与共享通知，不展示其他会话的通知。
- 红色表示影响会话进程的错误；黄色表示不影响会话进程、但需要用户知悉的问题，例如未识别的会话事件；绿色表示需要明确告知用户的重要变化，例如执行目录改变。
- 通知只补充不便在会话中展示、但需要用户关注的信息。发送失败、当前轮次执行失败等若已在会话正文或卡片中明确呈现，不再重复加入通知队列；局部操作已有明确原位反馈时同理。
- 分级依据是否影响会话执行或发送，不依据是否抛出异常：未被会话界面承接的阻断性错误为红色；保存图片、打开文件失败等局部操作问题为黄色；重要状态变化为绿色。常规复制成功、设置保存等反馈不入队。
- 未确认通知常驻，不因计时结束而静默消失；确认只表示知悉，不表示问题解决。
- 多条未确认通知按最新优先展示，确认当前通知后展示下一条未确认通知。
- 展开后可查看通知历史；新增命令「DSH：查看消息通知」，在没有顶部通知时仍可主动打开。
- 确认状态属于通知记录，在任一视图确认后同步到所有视图；其他视图按各自可见范围展示下一条未确认通知。
- 已确认通知仍保留在历史中，但不再占据顶部。
- 通知队列仅保存在扩展宿主内存中，不落盘；关闭再打开 DSH 面板、切换会话和断线重连均保留，重载 VS Code 窗口或退出后清空。
- 会话历史重放不重新产生旧通知。
- 同一归属、类型与关键内容的未确认重复通知合并，累加发生次数并更新最近发生时间；确认后再次实际发生，新增未确认记录并再次提醒，不修改旧的已确认记录。不同未知事件类型或不同执行目录属于不同关键内容。
- 历史重放或传输重发不算新的实际发生，不重复入队。
- 删除会话是终结性的：该会话的通知与去重水位随之清理，之后不再出现在任何视图；共享通知与其他会话的通知不受影响。
- 已确认历史最多保留最近 500 条；未确认通知不自动淘汰。

## 通知源边界

- 本次替换现有顶部提示与 webview 本地同类提示，不把 VS Code 原生错误弹窗整体迁入队列；原生交互弹窗仍保留。
- 会话正文里的通知段属于会话记录，不搬进通知队列。复制、保存、分支创建成功等已有明确结果的常规操作不入队。
- 未识别且不可忽略的实时会话事件为会话黄色通知；历史重放静默。影响输入内容理解的图片降级或不支持附件等变化，在没有明确原位说明时用黄色通知告知。
- 执行目录通知只来自实际实时变化；初始投影、跟随开帧、重连 baseline、切换视图或同水位重发均不作为新发生。能力缺失与 null 清空不是目录变更通知。
- 原生错误与顶部提示在同一失败路径完全重复时，只保留已有明确承接的一处；不借本次队列改造扩大原生通知范围。

## 展示与操作

- 顶部只展示可见范围内最近发生的未确认通知；合并重复发生也更新排序。使用明确的确认按钮，不以关闭图标、阅读、切换视图或计时替代确认。
- 展开入口打开通知抽屉，范围仍为当前会话与共享通知；整体按最近发生排序，逐条标明未确认或已确认，展示包含日期的最近发生时间、发生次数（包括 1 次）与完整会话 ID。
- 抽屉支持逐条确认。关闭抽屉或按 ESC 仅收起抽屉，不确认通知，不中止会话；顶部仍显示最近发生的可见未确认通知，确认后才让位于下一条。
- 新通知不自动弹开抽屉、不抢输入焦点；没有绑定会话的视图只展示共享通知。
- 命令「DSH：查看消息通知」在当前活动 DSH 视图打开抽屉；尚未实例化任何 DSH 视图时唤起主侧栏，不额外新建编辑区面板。视图尚未 ready 时暂存这次打开意图，在首帧状态送达后执行；不得广播打开所有视图。用户显式命令可以聚焦目标视图，自动到来的通知不得聚焦。队列为空时展示空态，全部确认后仍可查看历史。

## 权威与同步边界

- 扩展宿主控制器持有唯一内存队列，在逻辑发生点入队一次，再按各视图的当前会话分别下发完整镜像；不得在向多个视图投递的循环中重复计数。webview 只展示镜像，不本地确认或持久化通知。
- 确认携带稳定 ID 与用户当时看到的发生次数。宿主校验请求形状及该视图的可见范围；迟到确认只确认已展示的次数，后到的重复发生保留为新 ID 的未确认记录，旧 ID 的重复确认不能继续吞掉新发生。无效或过期确认仍回送权威镜像。
- 有持久事件序号的通知按所属会话的单调水位去重，不依赖会过期的短期事件缓存。真实删除会话时清理该会话的通知记录（未确认、已确认及部分确认的余量）与其去重水位；共享通知与其他会话的记录保留。关闭视图、归档与重连都不清理。
- 本地图片复制失败只上报固定类别与请求号，不接受任意文案、级别或路径。异步操作捕获发起会话，上报前与宿主接收时均校验归属；已切走的迟到失败丢弃。请求号在失败落定、即将上报时生成，避免并发操作完成乱序造成漏报。
- 执行目录通过投影来源区分实时增量与快照恢复；仍由既有投影存储及水位判断是否接纳变化，不另建一套目录事实。
