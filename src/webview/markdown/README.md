# src/webview/markdown/ — 正文 Markdown 管线

正文入口在 [components/Markdown.tsx](<../components/Markdown.tsx>)；本目录负责解析、代码源文提取、Windows 目标修复、完成态代码高亮、完成态数学**解析事实**、KaTeX 引擎 / 私有净化与整棵 mdast → React 渲染，业务只传文本、`phase` 与文件词表，不接触 mdast 类型。设计、阶段状态与验收见[Markdown 渲染设计](<../../../docs/design-markdown-rendering.md>)。阶段 3 已接入完成态代码高亮，正文与五类工具节点均通过 189 套离线断言和受控真实浏览器验收：工具节点覆盖 read 折叠上下文、diff 两侧 / hunk 隔离、inspect 稳定宿主与整段 JSON、write 源文保真、workflow 脚本，四主题 / copy / FindBar 已验证；阶段 4 的数学解析事实、KaTeX 引擎 seam、私有净化、本地 WOFF2 资源、MathView / 正文接线、display 段落切分与选区冻结已落地并通过主真实 UI 验收，FindBar 已接入搜索辅助层过滤，复制沿用原生选区（不做数学去重）；安装端资源 / 专用目录安装 / CSP / 字体已通过，系统剪贴板端到端与真实模型未覆盖；原始 HTML 按字面文本输出。

- [parse.ts](<parse.ts>) — `parseMarkdown(source, phase = "settled")` / `parseGfmMarkdown`：按 phase 选择 vendor GFM 或本地数学臂，随后修复 Windows 目标、收集文档级参考 / 脚注定义；缺失定义的脚注引用恢复为 `footnoteReference`，文中有代码时附带 `codeSources`。生产 `Markdown` 已改为 `parseMarkdown(text, phase)`：streaming 只走 GFM，settled 进入数学臂。
- [math.ts](<math.ts>) — 完成态数学解析适配：与 vendor 同集合单遍装配，包装公开 `math()` 文本 construct 做保守金额否决，包装 `mathFromMarkdown()` 的 `mathFlowFence` 记录权威闭合；`MathSource` 把 `form` / 定界符 / `closed` / 源码 offset / `raw` / 有效 `tex` 写进节点 data。`math` 围栏在 settled 由 `render.tsx` 经 `mathFenceSource` 转成 MathView，streaming 仍为 CodeBlock；`tex` / `latex` 仍走 CodeBlock。
- [mathRender.ts](<mathRender.ts>) — KaTeX 0.16.47 引擎 seam 与 `renderMath(source)`：闭合 / 长度 / 无 DOM 先拒，懒加载引擎；固定 `htmlAndMathml` / `trust:false` / `maxSize` / `maxExpand` / `globalGroup:false`，每式新宏表，真实 `katex-error` class token 判失败；净化失败或结构不确定回退 `undefined`。由 [MathView](<../components/MathView.tsx>) 在 settled 后懒调用。
- [mathSanitize.ts](<mathSanitize.ts>) — 数学输出私有 DOMPurify 净化：显式 tag / attr / namespace 白名单（HTML `span`、MathML 辅助语义、SVG `svg`/`path`/`line`），按 namespace + tag 校验属性，style 正向清洗，class 限定 0.16.47 真实集合；保留 `katex` / `katex-mathml` / `math` / `annotation` / `katex-html` 结构与辅助语义，未知结构整体回退。私有 `beforeSanitizeElements` hook 把 HTML parser 在 MathML text integration point 的 `mo` 里按 HTML namespace 重新建树的零属性纯文本 `mi` / `mn` / `mo` / `mtext` 折叠为文本（保留 `\mathop{lim}` 的辅助语义），其余混入辅助 MathML 的 HTML 元素令整式失败。导出 `sanitizeMathStyle` / `isAllowedMathAttribute` / `flattenableMisnamespacedMoTokenText` 供 Node 纯函数测试。
- [source.ts](<source.ts>) — `collectCodeSources` / `codePayload` / `sourceFallback`：用与解析同源的 micromark 事件流提取代码载荷（容器缩进、tab 虚拟列、NUL 与 CRLF 保真）；未知节点回退为安全源码片段。
- [windowsDestinations.ts](<windowsDestinations.ts>) — `fixWindowsDestinations`：解析后按源码位置恢复行内链接 / 图片的 Windows 绝对目标，把反斜杠编码为 `%5C`，已编码的目标不二次编码。
- [render.tsx](<render.tsx>) — `renderMarkdownDocument`：整棵 mdast 递归映射为 React（段落、列表、表格、引用、脚注、链接、任务列表、代码卡、MathView）；inline / display 公式按定界符事实进入私有 MathView，math 围栏用 `mathFenceSource`、tex / latex 仍走 CodeBlock；display 在段落 / tight-loose 列表 / 脚注里切成独立块并保留逻辑换行，strong / emphasis / delete / 已解析 link 会随公式拆开而不吞两侧内容。`MarkdownImage` 自持图片 pending / ready / failed，链接标题在渲染时合并，除私有 MathView 的已净化结果外不用 `innerHTML`、不做渲染后水合。
- [highlight.ts](<highlight.ts>) — 完成态代码高亮纯模块：Shiki 细粒度 core + JavaScript 正则引擎、21 种静态 grammar、语言别名、文件扩展名选语言、整段 token 按行裁剪、源码偏移 token、受控颜色 / 字形与成功 / 失败缓存；模块顶层不初始化引擎。接线与选区冻结在 `components/CodeBlock.tsx`、`components/useCodeHighlight.ts` 与 `components/HighlightedText.tsx`。
- [types.ts](<types.ts>) — `MarkdownPhase`：`streaming` / `settled`，缺省 `settled`；`CodeBlock` 只在 settled 初始化高亮，streaming 与 SSR 保持纯文本。
