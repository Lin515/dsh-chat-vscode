# src/webview/components/ — React 组件

运行环境：webview（浏览器环境，React）。上一层的说明见 [../README.md](../README.md)。

- `Composer.tsx` — 底部输入框：目标条、附件、发送 / 排队（队列行真的被截断时悬停看全文），弹层规则在 `../composerCompletion.tsx`，草稿里引用的蓝字镜像与 Ctrl 悬停手指光标在 `../composerMention.ts`（本组件只渲染镜像层并同步它的几何）；发送按钮的文字 / 停止态与点击手势走 `../composerSend.ts`，本组件只把按住态与事件交给它。局部编辑（改目标正文）里的 ESC 用 `../escapeOwner.ts` 的 `consumeEscape` 消费。
- `Message.tsx` — 单条消息：按 `MessageView` 种类装配正文、图片、工具行、折叠过程、轮尾文件；助手正文段本身不带复制入口，轮尾只保留时间 / 分支 / 复制 / 用时，复制载荷取本轮最后一段正文（`../turnProcess.ts` 的 `lastTextSegment`，与折叠边界同一条），不把工具前后的正文拼接冒充整条复制，用户消息整条复制保留；用户消息的正文在最前，其后是气泡内的附件区（文件芯片 `UserMedia`，再下面是图片缩略图），折叠只夹正文节点 `.bubble-text`（`UserBubble`）；已发出的 `@` 引用悬停给完整路径与 Alt 真实文件提示，HTML 文件另给 Ctrl/Cmd 浏览器提示（文件引用不复述「打开这个文件」——链接外观已经说明单击能打开）；Alt 打开可编辑真实文件，Ctrl/Cmd+HTML 交系统浏览器。
- `Markdown.tsx` — 正文入口的薄包装：把文本、phase 与文件词表交给 `../markdown/` 的解析与 React 文档树；streaming 只走 GFM，settled 解析数学；链接悬停补完整路径、Alt 真实文件提示与外链地址，点击按 `fileOpenIntent` 分流只读 / 真实文件 / Ctrl+HTML 浏览器。
- `MathView.tsx` — 私有公式视图：只接解析层确认的 `MathRenderSource` 与 phase；SSR / 首帧显示 `raw`，settled 后懒调 `renderMath` 并注入已净化 HTML，失败继续原文。结果带 `{phase, form, closed, raw, tex}` 的 JSON 渲染身份，render 期只显示匹配当前身份的那份，source 变 invalid 时第一帧回原文；选区冻结复用 `useSelectionFreeze` 保留完整 `{source, phase}` 快照（含 raw / form），应用异步结果前再用 `selectionIntersectsElement` 检查跨段 / 多 Range 选区，相交时等选区解除。主真实 UI 的布局、异步替换与选区冻结已通过；根 span 的 `data-math-view` 是搜索识别自有数学的唯一来源标识，不开放任意 HTML；查找据此跳过 MathML / annotation 辅助层，复制仍读原生选区、不再做数学去重。
- `CodeBlock.tsx` — 代码块卡片（复制按钮；markdown 与工具卡共用同一张卡片）；仅在 settled 阶段异步初始化语法高亮，迟到结果按请求代次隔离，活动选区与代码相交时冻结结果，span 文本始终由原 code 切片。正文 Markdown 里保留自己的卡片分区；被工具节点直接包住时不画第二圈外框，阅读框归 `.row-body`。字号取 `--font-size`，等宽只换字族。
- `useCodeHighlight.ts` — 代码高亮共享接线：归一化语言 + code 身份、异步取消、渲染前 key 核对与选区冻结；CodeBlock / read 卡 / diff 两侧 / 预览与 JSON 输出都复用它。
- `HighlightedText.tsx` — 受控 token 的 React 切片渲染与单块 `CodeText`（自带只提供主题变量的 `md-code-surface` 语义类，不引入卡片几何）。
- `ToolCards.tsx` — 按工具语义画的卡片（读 / 搜索 / 终端 / 网页），有卡片时不再展示参数 JSON；读卡在挂载时一次性 tokenize 完整返回窗口再按行切分（不逐行重置、不按显示上限截断上下文）。卡片只保留内部排版，阅读外框统一归外层 `.row-body`；内容字号取 `--font-size`。
- `Rows.tsx` — 通用行组件：审批卡、命令行、文件芯片、注入行、提问卡、思考行、工具行、轮统计等（文件芯片悬停依次给完整路径、按住 Ctrl/Cmd 单击打开只读副本、按住 Alt 打开可编辑的真实文件；默认点击是看对比，Ctrl/Cmd/Shift 保留原只读直接打开）。读 / 写 / 编辑与技能节点同一口径：按住 Alt 单击打开可编辑的真实文件、按住 Ctrl/Cmd 单击打开只读副本，两条提示各占一行、只读在前（技能只认服务端给的 `SKILL.md` 路径，没有就不提示）；这些节点的路径在悬停或按住修饰键时显示下划线，单击行为仍是开合；技能节点展开只显示 SKILL 正文，不显示参数与输出标题。每个展开阅读段套一次 `.row-body` 外框，同节点的 IN/OUT、diff 与输出等各段不合并滚动盒；`.row-body.is-action` 是动作行，保持无框。问卷「自定义回答」输入框里的 ESC 取消选中用 `../escapeOwner.ts` 的 `consumeEscape` 消费（文字保留）；输入框随内容自动长高，最多 5 行，再长在框内滚动，右下角可手动拖高、手动拖过后以手动高度为准（口径与算术在 `../questionInput.ts`）。workflow 的 `script`（旧 `code` 兜底）走代码块、其余参数保留在 IN；通用 IN 在完整参数解析为对象 / 数组且结算后按 JSON 着色（半截 / 标量 / 运行中纯文，始终同一 `CodeText` 宿主），明确 inspect 工具的成功整段 JSON OUT 按 JSON 着色，其余 OUT 原样纯文。IN / OUT 各有一枚图标复制按钮（官方通用 IN/OUT 不出复制，这是有意超集；悬停说明走 `toolCopyInput` / `toolCopyOutput` 以便读屏区分），思考 / 注入 / 技能正文 / 命令 / 未知块在展开体顶部、提示在行末、审批 / 计划待审在卡头、待答问卷在题面顶部也各有复制入口，空白内容不画；折叠行头本身是按钮，复制绝不嵌进去。正文取原文 / 当前冻结快照，结构化注入带字段，命令带名称 / 参数 / 结果，审批带工具 / 原因 / 详情，待答问卷带整组题目 / 详情 / 选项及当前填写状态（不冒充已提交）。已答 / 已取消 / 计划审阅记录卡保留展开体首右上角复制，普通问卷沿用 `../questionFlow.ts` 的 `questionReplyText`（官方 `replyClipboardText` 口径），计划记录额外包含完整计划原文；具体载荷纯函数在本文件。
- [WriteBody.tsx](<WriteBody.tsx>) — 仅 write 的参数原文预览与既有 diff 交接；共用阅读盒子、划选冻结与用户可脱离的贴底，不解释源码为 HTML／Markdown；运行中预览保持纯文，结算后才按目标文件语言着色。预览态的标签行右侧给复制（复制屏幕上那段原文），真有了 diff 就由 `Diff.tsx` 自己给入口。阅读盒与其它节点段共用 `.row-body` 外框和 `--font-size` 字号。
- `Diff.tsx` — diff 渲染：单栏 / 双栏两种排版；完成态按 hunk 的旧侧（context + del）与新侧（context + add）分别 tokenize，缺上下文只影响当前片段，不跨 hunk 拼整文件。第一段 hunk 的头部（路径 + `+N -M` 之后）有一枚复制按钮，复制整张卡的全部 hunk，载荷由 `shared/diff.ts` 的 `diffClipboardText` 拼（路径行 + `- ` / `+ ` / 两个空格前缀，含被折叠的行）。
- `Images.tsx` — 会话图片的统一呈现（用户 / 模型 / 工具 / 正文引用三处合成一套）+ 图片预览层。预览层支持滚轮以光标为锚点缩放、放大后左键拖动，右键菜单「复原」把倍率与平移清零；几何在 `../imagePreview.ts`。ESC 按 `../escapeOwner.ts` 的 `ESC_LAYER.imagePreview` 登记（右键菜单压过它）。
- `ChangesCard.tsx` — 轮尾改动文件卡片（数据来自宿主认证路由 `/api/changes.summary`；行悬停依次给完整路径、按住 Ctrl/Cmd 单击打开只读副本、按住 Alt 打开可编辑的真实文件）。普通单击看本轮快照对比，Alt 打开可编辑的真实文件，Ctrl/Cmd/Shift 保留原只读直接打开；每行带清单里的**原始下标**（折叠只减少可见行，不重编号）用于打开对比与悬停预热。
- `TodoPanel.tsx` — 会话底部的「任务清单」面板（`todo_write` 投影）：抬头带进度、可折叠，展开 / 收起走同一段行渲染；收起只留当前执行项（没有在执行的则留最后执行过的那条），抬头箭头展开朝下、收起朝上；开合态由 `App` 按会话记账（见 `../todoPanel.ts`）。
- [Trajectory.tsx](<Trajectory.tsx>) — 轨迹装配与账本／两个互斥检查器；折叠与搜索规则委托[行投影模块](<../trajectoryLedgerRows.ts>)，所有选择、focus、range、定位与视口通过[同一交互端口](<../trajectoryInteraction.ts>)。请求概述分别计工具／子工具，结果链接定位到助手消息或压缩记录。
- [TrajectoryTimeline.tsx](<TrajectoryTimeline.tsx>) — 时间线呈现层：只接收一个完整交互端口（含 plot ref），负责 ResizeObserver 与归一化跨度绘制，不另持有一套选择／手势状态。绘图区聚焦时的 ESC 由 `timelineEscape` 清选区与选中，并经 `../escapeOwner.ts` 的 `consumeEscape` 消费（不许落到「停止生成」兜底）。
- `TrajectoryPre.tsx` — 轨迹检查器里「一段原文」的统一呈现件（正文 + 复制 / 自动换行那对按钮）；`Trajectory.tsx` 里十几处都用它，新加一处原文就自动带上这两个动作。有标题行时那对按钮 portal 到标题行右侧（见 `TrajectorySection.tsx`），没有时留在正文上方一行。
- [TrajectorySection.tsx](<TrajectorySection.tsx>) — 概述页一节的**外壳**：标题行（标题 + 正文动作条插槽）+ 正文预览。动作条与标题同一行，正文紧贴标题，插槽经 context 交给正文块里的 `TrajectoryPre`。
- `SourceBlocks.tsx` — 轨迹检查器「原始内容」页签的逐块排版（对齐官方 `SourceBlocks()`）：每块一节（块标题 + 该块原文），块上有 `callId` 时标题变跳转按钮。
- `PromptDiff.tsx` — 轨迹检查器「差异」页签里的一节行级差分（对齐官方 `PromptDiffSection()`）：标题 + 逐行着色；行序列由 `../trajectoryPromptDiff.ts` 算。
- `TurnRail.tsx` — 右侧轮次横条组件：固定间距刻点、悬停预览卡、点击跳轮。
- `Panels.tsx` — 顶栏面板：后台任务抽屉（自动化任务分区 + 任务详情：实时输出、停止按钮）、子代理等抽屉。抽屉外壳（后台任务等）按 `../escapeOwner.ts` 的 `ESC_LAYER.drawer` 登记自己的关闭动作。
- [Schedules.tsx](<Schedules.tsx>) — 后台任务抽屉里的**自动化任务**分区（DSH `schedule`）：清单（四种读取状态各自成档）、运行时间编辑（草稿与已存规则比对后才亮保存栏）、执行记录（按需分页）与两段式删除。口径见[投影设计](<../../docs/design-projections.md#自动化任务schedule>)。
- `History.tsx` — 会话历史抽屉：搜索、顶部多选开关（在归档切换左边）切出的多选形态（形态下整行点选、全选、批量归档 / 恢复 / 删除，删除两次点击确认，与行内垃圾桶同一条口径）、行内归档 / 恢复 / 删除。多选判据在 `../sessionSelection.ts`，复选框自绘（样式在 `../styles/app.css`）。归档视图复用同一套逻辑、归档那颗换成恢复（`unarchiveSession`）。ESC 关抽屉走 `../escapeOwner.ts` 的 `ESC_LAYER.drawer`（自己消费，不落到会话页的停止生成）。
- [Notifications.tsx](<Notifications.tsx>) — 顶部常驻通知条与通知抽屉（宿主权威镜像，见[消息通知设计](<../../docs/design-notifications.md>)）：顶部只画最近一条未确认（文本区限高内滚，两颗按钮不被长正文挤掉），抽屉按最近发生顺序列出并逐条标出确认状态、时间、次数与完整会话 ID，逐条确认、没有全确认。选择 / 分组 / 时间格式化在 `../notifications.ts`；确认只回 `acknowledgeNotification`，界面不改本地列表。ESC 关抽屉走 `../escapeOwner.ts` 的 `ESC_LAYER.drawer`（只收起，不确认、不停生成）。
- `FindBar.tsx` — 会话查找条（Ctrl+F）：CSS Custom Highlight API 高亮 + 计数 + 上一处/下一处；纯逻辑在 `../find.ts`，跳命中（展开折叠气泡 → 放跟随 → 居中）走 `../readingPlacement.ts` 的同一个 `ReadingPort`。采文本时跳过可信 MathView 的辅助层、保留视觉层；inline 公式与相邻正文仍按文档序连续匹配，不另插块边界。打开查找的种子文字仍取原生 `Selection.toString()`。ESC 关查找走 `../escapeOwner.ts` 的浮层层级（不再自己挂 document 监听）。
- `EmptyMeta.tsx` — 空态页元信息：会话工作目录与 agent 预设。
- `ContextMenu.tsx` — 自绘右键菜单浮层（根部挂一次，只管画）。ESC 收菜单按 `../escapeOwner.ts` 的 `ESC_LAYER.contextMenu` 登记：压过原图浮层，一次 ESC 只关它。
- `CopyButton.tsx` — 复制按钮的**唯一**外观：一枚图标按钮（无文字标签），成功态只把图标换成对勾并上成功色（1s），悬停说明与无障碍名由 `title` 给出。用户气泡、助手轮尾、思考 / 注入 / 技能 / 命令 / 提示 / 未知块、审批 / 待答问卷 / 计划 / 记录卡、工具卡、diff 头部、IN/OUT 标签行、写入预览、后台任务详情、历史会话 ID、代码块、轨迹原文全部复用它；文字只留在读屏的 `sr-only` live region 里。文件里还有轨迹自动换行开关 `WrapLinesButton`，以及没有按钮可换文案的复制入口用的提示层 `CopyFlashLayer`（同样只闪一枚对勾）。状态机、计时与剪贴板写入在 `../copyFeedback.ts`，本文件只画外观。
- `primitives.tsx` — 小组件与格式化工具（Popover、`formatClock`、路径拆分展示等）；Popover 带可选 `className` 作为分区挂点（模型弹层靠它把可滚的模型列表与常驻的思考档位区拆成两层，见 `Composer.tsx`）。上下文占用的圆环与它的悬停明细也在这里，明细拼法 `contextDetailLines` 是**唯一一份**（工具栏那枚缓存命中读数的悬停也读它，两处信息刻意保持一致）。
